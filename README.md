# NextTodo
## 概要

こちらは、TypeScript, React, Next.jsの学習のために開発したアプリです。
開発を通して、gitの操作に慣れ、AI開発に触れることができました。そして、TypeScript, React, Next.jsの概要を掴むことができました。

## 使用した技術
- TypeScript ( https://www.typescriptlang.org/ )
- React ( https://react.dev/ )
- Next.js ( https://nextjs.org/ )
- prisma ( https://www.prisma.io/ )
- Neon ( https://neon.com/ )
- Cursor ( https://cursor.com/ )
- Vercel ( https://vercel.com/ )

## 使い方

### 1. ブラウザで以下にアクセスしてください。
https://next-todo-jade-five.vercel.app/

### 2. Basic認証画面で、指定のユーザー名とパスワードを入力してください。

認証に成功すれば、タスクを追加、チェックボックスにチェックを入れて削除できます。
